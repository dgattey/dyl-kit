# Release notes

- Replaced the waveform icon with the new "Scone Cone" icon (a baked scone wedge speaker cone with honey-glass sound arcs) across macOS, iOS, the web landing icon, and the in-app sidebar emblem.
- Fixed light, dark, and tinted app icon switching across macOS 26 and iOS 26 so the app icon and in-app emblem dynamically match the active appearance.

# What changed?

- **Why only the dark icon shipped previously**:
  1. `scripts/generate-icon.swift` wrote only the dark iconset into `build/AppIcon.icns`, and `Assets.xcassets/AppIcon.appiconset/Contents.json` only declared `"appearances": [{"appearance": "luminosity", "value": "dark"}]` for `"idiom": "mac"`, omitting a default/light macOS slot.
  2. On macOS 26, `xcrun actool` ignores `"appearances"` inside legacy `.appiconset` folders for `"idiom": "mac"` and only emits appearance-aware `AppIcon.iconstack` renditions (`NSAppearanceNameAqua`, `NSAppearanceNameDarkAqua`, `ISAppearanceTintable`) into `Assets.car` when compiling an Icon Composer `AppIcon.icon` bundle.
  3. `scripts/build-ios-sim.sh` did not compile an asset catalog into `Assets.car` or set `CFBundleIconName = AppIcon` in `Info.plist`.
- **Scone Cone CoreGraphics generator & Icon Composer `.icon` bundle (`scripts/generate-icon.swift`)**:
  - Ported the Scone Cone artwork (`concept-2.svg` light and `concept-2-dark.svg` dark, plus a monochrome tinted specialization) directly into CoreGraphics at 16px–1024px with adaptive small-size tuning so 16px and 32px remain crisp.
  - Emits `build/AppIcon.icon` (`icon.json` + `Assets/scone-cone-{light,dark,tinted}.png` with light/dark fill and layer specializations), `build/Assets.xcassets/AppIcon.appiconset` (including both light and dark macOS + iOS slots), `build/AppIcon-Light.icns`, `build/AppIcon-Dark.icns`, `build/AppIcon.icns`, and `server/public/app-icon.png`.
- **macOS & iOS build scripts (`scripts/build-macos.sh`, `scripts/build-ios-sim.sh`, `Sources/SconeosApp/SconeosMain.swift`)**:
  - Compiles `build/AppIcon.icon` via `xcrun actool` into `Assets.car` (`AppIcon.iconstack` with `NSAppearanceNameAqua`/`UIAppearanceLight`, `NSAppearanceNameDarkAqua`/`UIAppearanceDark`, and `ISAppearanceTintable`).
  - Bundles `AppIcon-Light.icns` and `AppIcon-Dark.icns` into `Sconeos.app/Contents/Resources/` and observes `NSApp.effectiveAppearance` in `SconeAppDelegate` so the running Dock tile also switches immediately when toggling macOS Light/Dark mode.
- **In-app `SconeBrandEmblem` (`Sources/SconeUI/MidnightGlassTheme.swift`)**:
  - Replaced the old waveform bars with `SconeConeWedgeShape` (3D biscuit crumb base, baked golden top, gloss highlight, and sugar crystals at >=22pt) and `SconeConeSoundArcShape` (two honey-glass sound arcs with inner specular highlights), adapting to `@Environment(\.colorScheme)`.
